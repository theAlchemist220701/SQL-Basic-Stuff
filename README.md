# SQL Basics — My Learning Journey

## About This Repository

This repository contains the SQL queries and scripts I wrote while following the [SQL Tutorial by Alex The Analyst on YouTube](https://www.youtube.com/watch?v=OT1RErkfLNQ).

I created these files to document my progress, practice SQL concepts, and build a reference that I can revisit as I continue learning.

The scripts contain my hands-on practice from the tutorial, covering fundamental SQL queries through more advanced database concepts.

## Topics Covered

- SQL fundamentals and `SELECT` statements
- Filtering data using `WHERE` and logical operators
- Sorting, grouping, and filtering grouped results
- Joins
- `UNION` and `UNION ALL`
- String functions
- `CASE` statements
- Subqueries
- Window functions
- Common Table Expressions (CTEs)
- Temporary tables
- Stored procedures and parameters
- Triggers and events

## Repository Structure

The numbered SQL files are organized by the topics covered during the tutorial.

Each file contains the SQL code I wrote while learning and practicing the corresponding concepts.
